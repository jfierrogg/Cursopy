1. Interacción con Checkbox (Sin Script)

¡Este texto se muestra u oculta haciendo clic en el botón!

Esto demuestra que puedes crear un **Toggle** (alternancia) usando solo HTML y CSS.

document.addEventListener("DOMContentLoaded", () => { const btn = document.getElementById("btn-arriba"); window.addEventListener("scroll", () => { if (window.scrollY > 300) { btn.classList.add("visible"); } else { btn.classList.remove("visible"); } }); btn.addEventListener("click", () => { window.scrollTo({ top: 0, behavior: "smooth" }); }); });
